# Налоговые паспорта субъектов Российской Федерации

Полный архив налоговых паспортов с [аналитического портала ФНС России](https://analytic.nalog.gov.ru/) за 2014–2024 годы. Он разобран в базу данных с сохранением структуры исходных таблиц.

| | |
|---|---|
| Первоисточник | Аналитический портал ФНС России, `https://analytic.nalog.gov.ru/api/TaxPassports/ExportAll?year=<год>` |
| Владелец данных | ФНС России |
| Период | 2014–2024 отчётные годы (срезы на 01.01.2015 … 01.01.2025) |
| Охват | 85 субъектов (83 в 2014 году), 8 федеральных округов, РФ — 1 032 паспорта |
| Объём | 11 архивов ZIP (72 МБ), 1,83 млн значений, 439 тыс. строк таблиц |
| Форматы | исходные XLS в ZIP; база DuckDB; таблицы Parquet |
| Дата загрузки | 03.11.2026 (первая — 20.03.2025) |

## Содержание паспорта

Каждый паспорт — книга Excel с 10–12 разделами:

1. Социально-экономическая характеристика (Росстат): ВРП, промышленность, торговля, доходы, занятость, число налогоплательщиков
2. Налоговая база по основным налогам и спецрежимам
3. Льготы — суммы налогов, не поступившие в бюджет
4. Контрольная работа: выездные и камеральные проверки, доначисления
5. Поступления по видам доходов и уровням бюджетов
6. Страховые взносы (с 2017 года)
7. Поступления по видам экономической деятельности
8. Задолженность по налогам и сборам (2014–2022)
9. Задолженность по видам экономической деятельности (2014–2022)
10. Налоговая нагрузка в % к ВРП
11. Налоговая нагрузка по видам экономической деятельности
12. Оценка и прогноз поступлений

Номера листов в разные годы означают разное. Подробности — в [docs/source-format.md](docs/source-format.md), полный перечень показателей — в [docs/catalog/](docs/catalog/README.md).

## Быстрый старт

Готовые таблицы лежат в `data/parquet/`:

```python
import duckdb
duckdb.sql("""
    SELECT p.year, t.name, v.value AS grp_bln_rub
    FROM 'data/parquet/value.parquet' v
    JOIN 'data/parquet/sheet.parquet' s USING (year, territory_code, sheet_name)
    JOIN 'data/parquet/territory.parquet' t USING (territory_code)
    JOIN 'data/parquet/passport.parquet' p USING (year, territory_code)
    WHERE s.theme_code = 'socio_economic' AND v.row_code = '101' AND v.col_no = 3
      AND t.kind = 'region' AND p.year = 2024
    ORDER BY v.value DESC LIMIT 10
""").show()
```

Подробные примеры — от отдельной ячейки паспорта до временных рядов, сравнения регионов и графиков — собраны в тетрадке Jupyter [docs/examples.ipynb](docs/examples.ipynb). Она работает по Parquet и не требует сборки базы:

```bash
make venv && make notebook
```

Полная база с представлениями (`v_value`, `v_indicator`, `v_column`) собирается из скачанных архивов:

```bash
make venv     # окружение .venv (нужен uv)
make build    # data/db/regtaxpassports.duckdb + data/parquet/
make test
```

Обновить данные с портала (нужен российский IP, см. [docs/collection.md](docs/collection.md)):

```bash
REGTAX_PROXY=socks5h://127.0.0.1:1080 make collect
```

## Важные оговорки

- Паспорта округов и РФ — готовые итоги. Не складывайте их с субъектами.
- Внутри раздела итоги и детализация лежат вместе («ВСЕГО», «в том числе», «из них»). Иерархия задана полем `parent_code`.
- `X` и `-` в исходных таблицах — это не ноль: в базе у таких ячеек `value IS NULL`, а текст сохранён в `value_text`.
- В части разделов единица в файлах не указана. Для поступлений, льгот, страховых взносов и задолженности принято «млн. руб.» (`unit_source = 'theme_default'`, обоснование — в [docs/source-format.md](docs/source-format.md#единицы-измерения)).
- Лист «Руководители» (ФИО, адреса, телефоны должностных лиц) в базу не загружается. В исходных архивах он есть.
- ФНС пересматривает опубликованные паспорта: паспорт РФ за 2023 год изменился между загрузками. Изменения выводятся в `value_revision`.
